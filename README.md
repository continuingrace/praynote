# Pray Note

하루의 기도 제목을 간결하게 기록하는 개인용 웹 노트입니다.

**Current version: v1.0.0**

## v1.0.0

- 하루 기본 기도 제목 5개
- 필요한 만큼 기도 항목 추가
- 추가 항목 삭제
- 기도 완료 체크 및 진행률 표시
- 날짜별 기록 분리
- 이전 날짜 / 다음 날짜 / 오늘 이동
- 오늘 마음에 남은 말씀·문장 기록
- 브라우저 `localStorage` 자동 저장
- Pretendard 기반 반응형 미니멀 UI
- 앱 상단 버전 넘버 상시 표시

## 사용

별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 사용할 수 있습니다.

> 현재 데이터는 사용 중인 브라우저의 로컬 저장소에만 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기 사용 시 기록이 자동 동기화되지 않습니다.

## Version rule

화면 상단의 버전과 코드의 `VERSION` 값을 함께 관리합니다. 기능 추가 및 UI 업데이트 시 SemVer 형식으로 버전을 올립니다.
